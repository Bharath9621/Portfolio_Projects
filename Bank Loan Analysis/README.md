# 💰 Bank Loan Analytics & Risk Monitoring

An end-to-end Business Intelligence project that analyzes loan portfolio performance, customer lending behavior, and credit risk using SQL, Python, and Power BI. The solution enables financial institutions to monitor loan performance, identify lending trends, evaluate borrower risk, and support data-driven lending decisions.

---

# 📌 Project Overview

Financial institutions generate large volumes of lending data that can be leveraged to improve credit risk assessment, monitor portfolio health, and optimize lending strategies.

This project demonstrates how SQL, Python, and Power BI can be combined to transform raw loan data into meaningful business insights through interactive dashboards and KPI reporting.

---

# 🎯 Business Objectives

This project helps answer key business questions such as:

- What is the total funded loan amount?
- What percentage of loans have been fully repaid?
- Which customer segments have the highest default rates?
- How do loan applications vary over time?
- Which loan purposes generate the highest revenue?
- What factors influence loan defaults?
- How does borrower income affect repayment behavior?

---

# 🚀 Business Problems Solved

### Loan Portfolio Monitoring

Tracked overall lending performance using key financial KPIs.

### Credit Risk Analysis

Identified borrower segments with higher default probabilities.

### Customer Segmentation

Analyzed lending behavior based on demographics and financial attributes.

### Lending Performance

Compared funded amounts, repayments, and outstanding balances.

### Executive Reporting

Developed dashboards enabling management to monitor portfolio health in real time.
